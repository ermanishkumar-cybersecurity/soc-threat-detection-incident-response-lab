# Incident Investigations

This directory contains incident investigation documentation from the SOC threat detection lab.

## Investigation Areas

- Brute-force authentication
- Suspicious PowerShell activity
- Privilege escalation
- Abnormal process execution

## Investigation Process

1. Review the security alert.
2. Examine relevant Windows Event Logs and Sysmon telemetry.
3. Correlate related events.
4. Identify suspicious activity and IOCs.
5. Build the attack timeline.
6. Identify affected systems.
7. Assess the incident severity.
8. Map observed behavior to MITRE ATT&CK.
9. Document findings.
10. Recommend remediation actions.
