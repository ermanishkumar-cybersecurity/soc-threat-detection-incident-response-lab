# MITRE ATT&CK Mapping

This directory contains MITRE ATT&CK mappings for behaviors investigated during the SOC threat detection and incident response lab.

## Mapped Attack Behaviors

The lab focuses on mapping observed behaviors to relevant MITRE ATT&CK techniques based on the available Windows Event Logs and Sysmon telemetry.

### Investigation Areas

- Brute-force authentication
- Suspicious PowerShell activity
- Privilege escalation
- Abnormal process execution

## Mapping Process

1. Identify the observed attacker behavior.
2. Review supporting Windows Event Logs and Sysmon events.
3. Determine the relevant MITRE ATT&CK tactic and technique.
4. Document the evidence supporting the mapping.
5. Record the associated indicators of compromise.
6. Include the mapping in the incident investigation report.

## Documentation

Each mapping should include:

- Observed behavior
- Supporting log evidence
- MITRE ATT&CK tactic
- MITRE ATT&CK technique
- Indicators of compromise
- Investigation notes
- Recommended defensive actions
